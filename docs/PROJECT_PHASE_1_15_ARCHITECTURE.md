# 中级会计 AI 学习助手项目 Phase 1-15 总体架构

## 项目目标

打造面向中级会计考试（财务管理、经济法）的 AI 私教系统。

当前考试状态：
- 剩余33天
- 每日学习120-150分钟
- 单次30-60分钟碎片化学习
- 最后4天进入冲刺刷题模式

---

# Phase 1-5 基础体系

建立：
- Skills体系
- 学习规划Agent
- 财管Agent
- 经济法Agent
- 错题管理体系
- 倒计时学习框架

# Phase 6-10 智能学习系统

建立：
- 碎片化时间调度
- 高频知识库
- 公式记忆库
- 法条记忆库
- 用户学习画像
- 掌握度评分
- 自适应复习算法

# Phase 11-14 考试智能系统

建立：
- 模拟考试生成器
- 得分预测模型
- RAG知识检索体系
- Agent Router
- Workflow Engine
- Memory管理

# Phase 15 Skill封装

建立统一入口：

用户可以通过：
- 开始今日学习
- 学习指定章节
- 刷题
- 错题复盘
- 冲刺模式

启动完整学习流程。

# 核心学习逻辑

优先级：

1. 错题修复
2. 高频考点
3. 真题训练
4. 公式/法条强化
5. 新知识补充
