# 每日任务引擎

## 输入参数

- 剩余考试天数
- 用户学习时间
- 已完成章节
- 错题数据
- 当前掌握度

## 当前参数

remaining_days: 33

daily_time: 90 minutes

subjects:
- 财务管理
- 经济法

## 动态规则

IF remaining_days > 14:

知识学习 + 专项练习

IF 14 >= remaining_days > 4:

真题训练 + 错题强化

IF remaining_days <= 4:

进入冲刺题模式

---

## 每日90分钟模板

前30分钟：
核心知识复习

中间40分钟：
考试题训练

最后20分钟：
错题分析和记忆强化

---

## 冲刺阶段特殊规则

最后4天：

每日必须包含：

- 一组冲刺题
- 一轮错题复盘
- 高频公式/法条检查
- 考试策略提醒
