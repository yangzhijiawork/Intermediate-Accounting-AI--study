# 碎片化时间自适应学习引擎

## 用户学习约束

考试剩余：33天

每日投入：2-2.5小时

单次学习：约1小时

实际场景：
- 多次30分钟碎片时间
- 不保证连续学习

## 核心策略

AI不再按照固定90分钟任务生成，而采用时间块管理。

---

# 每日学习总量模型

目标：150分钟左右

拆分：

Block A（30分钟）
知识输入

Block B（30分钟）
例题训练

Block C（30分钟）
专项刷题

Block D（30分钟）
错题复盘

Block E（30分钟）
记忆强化/公式法条

用户可以根据实际时间完成任意组合。

---

# 单次任务设计原则

每个任务必须满足：

- 30分钟可完成
- 有明确开始和结束
- 有即时反馈
- 可记录学习结果

示例：

财管：
30分钟完成10道资本成本计算题。

经济法：
30分钟背诵并测试20个公司法关键词。

---

# AI调度规则

如果用户只有30分钟：

优先：
1. 错题
2. 高频考点
3. 必考公式/法条

如果用户有60分钟：

组合：
知识学习 + 训练

如果用户有120分钟以上：

执行完整学习循环。

---

# 最后4天调整

每个30分钟块全部转为：

- 冲刺题
- 错题
- 高频记忆
- 模拟训练

禁止安排长篇新知识学习。
